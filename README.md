# Library System

## Description

Simple Library Information System

## Requirements

- PHP
- Composer
- MySQL
- Laravel

## Installation

1. Clone the repository: `git clone <link-repo>`
2. Go to the project directory: `cd library-system`
3. Install dependencies: `composer install`
4. Copy `.env.example` to `.env` and configure your database setup
5. Generate app key: `php artisan key:generate`
6. Run migrations: `php artisan migrate`
7. Start the local server: `php artisan serve`
